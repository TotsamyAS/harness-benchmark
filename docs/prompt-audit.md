# Проверка ограничений промпта

Статическая проверка; влияние на качество пока не измерено платными прогонами.

| Наблюдение | Изменение / следствие |
|---|---|
| Запреты могли восприниматься как запрет обрабатывать секреты вообще | Явно разрешена локальная обработка и включение необходимых секретов во внутренний результат. Запрет относится к advisor и внешнему адресату |
| Запрет «не исполняй произвольный код» мог мешать генерации HTML | Явно разрешены JavaScript в HTML и локальные библиотеки; сетевые обращения по-прежнему запрещены |
| Повторяющиеся подробные запреты увеличивали контекст | Системная инструкция сокращена и переведена на английский |
| Модель не может выполнять Python/shell | Это ограничение набора инструментов, не промпта; его нельзя устранить переформулировкой |
| generic_only почти лишает advisor контекста для смысловых секретов | Это ограничение политики защиты; оценивать отдельно от способности модели выполнить задание |
| Английский может менять не только токены, но и качество | Экономию и качество необходимо измерять отдельно для каждой модели |

Служебные инструкции агента, задания и инструкция судьи теперь английские. Исходные документы, имена сущностей,
русская разметка критериев/секретов и пользовательская документация сохраняют язык данных. Результаты и объяснения
должны быть русскими, кроме явно заданного перевода на китайский.

Для количественной проверки нужен отдельный парный эксперимент: прежний подробный промпт против сокращённого,
с одинаковым языком, входами, моделью, инструментами, политикой защиты и бюджетом шагов. Перевод языка проверять
отдельной парой RU/EN, иначе нельзя отделить влияние языка от содержания. Не ослаблять конфиденциальность в контрольной группе.
Сравнить подтверждённое качество, отказы, завершённые файлы, вызовы advisor, ошибки инструментов, утечки и токены.
Такой эксперимент пока не запускался; улучшение качества или экономия не заявляются.
